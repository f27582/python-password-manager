# Python Password Manager

A beginner-level password manager project built with Python.

## Features

- Add a password with a person ID
- Search for a password using a person ID
- Delete a password using a person ID
- Display stored password records
- Menu-based interaction
- Exit the program

## Concepts Practiced

This project was created to practice fundamental Python concepts, including:

- Lists and nested lists
- `input()`
- `if`, `elif`, and `else`
- `for` loops
- `while` loops
- `append()`
- `remove()`
- `break`
- Searching through lists
- Updating and deleting data
